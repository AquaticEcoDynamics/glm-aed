Configuration reference

A GLM simulation is configured via the main “namelist” (nml) text file called glm3.nml or glm4.nml. Each block of configuration options and parameters is summarised below. For a summary of the notation and nomenclature refer to the 2019 GMD paper.

For working examples, visit glm-examples.

No variables match that filter.

Model Configuration

&glm_setup

The first block IS compulsory, with the following variables that may be set :

Variable Name Symbol Description Type Units Options Default
sim_name Title of simulation [string] 'lake'
max_layers $$N_{MAX}$$ Maximum number of layers [integer] - 500
min_layer_vol $$\Delta V_{min}$$ Minimum layer volume [real] $$m^3$$
min_layer_thick $$\Delta z_{min}$$ Minimum thickness of a layer (m) [real] $$m$$
max_layer_thick $$\Delta z_{max}$$ Maximum thickness of a layer (m) [real] $$m$$
density_model $$\Theta_{\rho}$$ Switch to set the density equation [integer] - $$\rho[T,S] \longleftarrow \left\{ \begin{array}{ll} \textrm{UNESCO(1981): }&\Theta_{\rho}=0 \\ \textrm{TEOS-10: }&\Theta_{\rho}=1 \end{array} \right.$$ 0
non_avg $$\Theta_{bc}$$ Switch to configure flow boundary condition temporal interpolation [boolean] - $$Q_{inf}^{t} = \left\{ \begin{array}{ll} Q_{inf}^{t} & \Theta_{bc}=T \\ (Q_{inf}^{t}+Q_{inf}^{t-1})/2 & \Theta_{bc}=F \end{array} \right.$$ .false.
Example 
&glm_setup
			   sim_name = 'Example Simulation #1'
			   max_layers = 500
			   min_layer_thick = 0.15
			   max_layer_thick = 1.50
			   min_layer_vol = 0.025
			   density_model = 1
			   non_avg = .true.
			/

&mixing

This configuration block is NOT compulsory

Variable Name Symbol Description Type Options Default
surface_mixing $$\Theta_{mix}$$ Switch to select the options of the surface mixing model [integer] $$ \left\{ \begin{array}{ll} \textrm{No surface mixing }&\Theta_{mix}=0 \\ \textrm{xxxxx }&\Theta_{mix}=1\\ \textrm{xxxxx }&\Theta_{mix}=2 \end{array} \right.$$ 1
coef_mix_conv $$C_{K}$$ Mixing efficiency - convective overturn [real]
coef_wind_stir $$C_{W}$$ Mixing efficiency - wind stirring [real]
coef_mix_shear $$C_{S}$$ Mixing efficiency - shear production [real]
coef_mix_turb $$C_{T}$$ Mixing efficiency - unsteady turbulence effects [real]
coef_mix_KH $$C_{KH}$$ Mixing efficiency - Kelvin-Helmholtz billowing [real]
deep_mixing $$\Theta_{deep}$$ Switch to select the options of the deep (hypolimnetic) mixing model [integer] $$ \left\{ \begin{array}{ll} \textrm{No deep mixing: }D_z=0&\Theta_{deep}=0 \\ \textrm{Constant diffusivity: }D_z=C_{HYP}&\Theta_{deep}=1\\ \textrm{Weinstock model: }D_z=f(N^2,C_{HYP},...)&\Theta_{deep}=2 \end{array} \right.$$ ?
coef_mix_hyp $$C_{HYP}$$ Mixing efficiency - hypolimnetic turbulence [real]
diff $$D_{\epsilon}$$ Background (molecular) diffusivity in the hypolimnion [real]
Example 
&mixing
			  surface_mixing = 1
			  coef_mix_conv  = 0.125
			  coef_wind_stir = 0.23
			  coef_mix_shear = 0.2
			  coef_mix_turb  = 0.51
			  coef_mix_KH    = 0.3
			  deep_mixing    = 2
			  coef_mix_hyp   = 0.5
			  diff = 0.
			/

&wq_setup

This configuration block is NOT compulsory

Variable Name Symbol Description Type Options Default
wq_lib $$\Theta_{wq}$$ Water quality model selection [string] $$ \left\{ \begin{array}{ll} \textrm{FABM} & \Theta_{wq}=\textrm{'FABM'} \\ \textrm{AED2} & \Theta_{wq}=\textrm{'AED2'} \\ \end{array} \right.$$ AED2
wq_nml_file Filename of WQ configuration file [string] add filename in quotes, can include directorys './aed2.nml'
bioshade_feedback $$\Theta_{kw}$$ Switch to enable \(K_{w}\) to be updated by the WQ model [boolean] $$K_{w}[t,z] = \left\{ \begin{array}{ll} K_{w} & \Theta_{kw}=F \\ K_{w}+K_{ss}+K_{dom}+K_{pom}+K_{phy} & \Theta_{kw}=T \\ \end{array} \right.$$ ?
mobility_off Switch to enable settling within the WQ model [boolean] .true. & .false. .false.
ode_method $$\Theta_{ode}$$ Method to use for ODE solution of water quality module [integer] tbc 1
split_factor Factor weighting implicit vs explicit numerical solution of the WQ model [real] 0-1 1
repair_state $$\Theta_{repair}$$ Switch to correct negative or out of range WQ variables [boolean] .true. or .false. .true.
Example 
&wq_setup
			   wq_lib = 'aed2'
			   wq_nml_file = 'aed2/aed2.nml'
			   ode_method = 1
			   split_factor = 1
			   bioshade_feedback = .true.
			   repair_state = .true.
			   mobility_off = .false.
			/

&time

This configuration block IS compulsory

Variable Name Symbol Description Type Options Default
timefmt $$\Theta_{time}$$ Time configuration switch [Integer] $$ \left\{ \begin{array}{ll} t = t_{0} ... t_{N_{\Delta t}};\ N_d = t_{N_{\Delta t}} - t_{0} & \Theta_{time}=2 \\ t = t_{0} ... (t_{0}+N_d);\ t_{N_{\Delta t}} = t_{0}+N_d & \Theta_{time}=3 \\ \end{array} \right.$$ ?
start $$t_{0}$$ Start time/date of simulation [string, format = "yyyy-mm-dd hh:mm:ss"] Required -
stop $$t_{N_{\Delta t}}$$ End time/date of simulation [string, format = "yyyy-mm-dd hh:mm:ss"] Used when (\(\Theta_{time}=2\)) -
dt $$\Delta t$$ Time step (\(sec\)) [real] Required 3600
num_days $$N_d$$ Number of days to simulate [integer] Used when (\(\Theta_{time}=3\)) -
timezone $$TZ$$ UTC time zone [real] +0
Example 
&time
				   timefmt  = 3                       ! Choose 2 (start/stop) or 3 (num_days)
				   start    = '1997-01-01 00:00:00'
				   stop     = '1999-01-01 00:00:00'
				   dt       = 3600.0
				   num_days = 730
				  !timezone = 7.0
				/

csv_point_at Height or Depth of points to output at (comma separated list) [real] 0
csv_point_nvars Number of variables to output into the csv files [integer]
csv_point_vars Comma separated list of variable names [string] temp; salt; ...
csv_outlet_allinone Switch to create an optional outlet file combining all outlets [boolean] .true. & .false. .false.
csv_outlet_fname Name to be appended to each of the outlet CSV files [string]
csv_outlet_nvars Number of variables to be written into the outlet file(s) [integer] 0

				   csv_point_nlevs = 2

				   csv_point_at    = 5,30    ! a file will be produced for 5m and 30m heights from bottom
				   csv_point_nvars = 7
				   csv_point_vars  = 'temp',
						     'salt',
							'OXY_oxy',
							 'SIL_rsi',
							 'NIT_amm',
							 'NIT_nit',
							 'PHS_frp'
				  !-- Combined outlet file & overflow
				   csv_outlet_allinone = .false.
				   csv_outlet_fname = 'outlet_'
				   csv_outlet_nvars = 4
				   csv_outlet_vars = 'flow',
				                     'temp',
				                     'salt',
				                     'OXY_oxy',
				   csv_ovrflw_fname = "overflow"
				/

&particles

Configures the Particle Tracking Model (PTM), which advects Lagrangian particles through the layer structure. This block is optional; if it is absent GLM reports “No 'particles' config, assuming no particles” and continues. Particles are only stepped when ptm_sw is .true.

Variable Name Symbol Description Type Options Default
ptm_sw $$\Theta_{ptm}$$ Switch to enable the particle tracking model [boolean] .true. OR .false. .false.
num_particle_grp $$N_{grp}$$ Number of particle groups. Accepted by the reader; planned for future update — the group count applied internally is fixed at 1 [integer] - 1
max_particle_num $$N_{max}$$ Maximum number of particles that may exist at any one time. This sizes the particle arrays, so raising it raises the memory footprint [integer] \(\le 10000\) 10000
init_particle_num $$N_{init}$$ Number of particles seeded at the start of the simulation [integer] \(\le\) max_particle_num 10
init_depth_min $$z_{min}$$ Shallowest depth of the band the initial particles are seeded into, measured down from the water surface (\(m\)) [real] - 0.0
init_depth_max $$z_{max}$$ Deepest depth of the band the initial particles are seeded into, measured down from the water surface (\(m\)) [real] \(>\) init_depth_min 2.0
inflow_conc $$C_{ptm}[1...N_{inflow}]$$ Particle concentration carried by each inflow (\(\#\;m^{-3}\)). One value per inflow, in the order the inflows are declared in &inflow [array] comma-separated list 0
ptm_diffusivity $$K_{ptm}$$ Floor applied to the vertical diffusivity used in the particle random walk (\(m^{2}\,s^{-1}\)). Where the resolved \(K_z\) falls below this value, this value is used instead [real] - 1e-6
ptm_time_step $$\Delta t_{ptm}$$ Sub time step for particle motion. Accepted by the reader; planned for future update. Note the source initialiser is written 1/60, which is integer division in C and therefore evaluates to \(0\), not one minute [real] - 0
particle_density $$\rho_{p}$$ Density assigned to each particle (\(kg\;m^{-3}\)), used in the settling calculation [real] - 1000.0
particle_diameter $$d_{p}$$ Diameter assigned to each particle (\(m\)), used in the settling calculation [real] - 1e-6
settling_velocity $$v_{s}$$ Prescribed particle settling velocity (\(m\;s^{-1}\)). Negative values sink [real] - 0.0
settling_efficiency $$\eta_{s}$$ Scales the probability that a particle reaching the bottom layer is retained by the sediment. \(1\) retains every particle that arrives [real] \(0 \le \eta_{s} \le 1\) 1.0
sed_deactivation $$\Theta_{sed_{ptm}}$$ Switch to deactivate particles once they settle to the sediment, rather than leaving them available for resuspension [boolean] .true. OR .false. .false.
do_particle_bgc $$\Theta_{bgc_{ptm}}$$ Switch to enable particle-attached biogeochemistry. The flag is passed through to AED, so it only has an effect when a water quality model is active [boolean] .true. OR .false. .false.
Example 
&particles
   ptm_sw            = .true.
   max_particle_num  = 10000
   init_particle_num = 1000
   init_depth_min    = 0.0
   init_depth_max    = 2.0
   ptm_diffusivity   = 1e-6
   particle_density  = 1000.0
   particle_diameter = 1e-6
   settling_velocity = 0.0
/

&meteorology

cloud_mode $$\Theta_{cloud}$$ Switch to configure which atmospheric emmissivity calculation option is used [integer] $$ \left\{ \begin{array}{ll} \textrm{Idso and Jackson } & \Theta_{cloud}=1 \\ \textrm{Swinbank } & \Theta_{cloud}=2 \\ \textrm{Brutsaert } & \Theta_{cloud}=3 \\ \textrm{Yajima & Yamamoto} & \Theta_{cloud}=4 \end{array} \right.$$
lw_factor $$f_{LW}$$ Scaling factor to adjust the longwave (or cloud) data provided in the meteo_fl (\(C_x\)) [real] 1
Sensible & latent heat
atm_stab $$\Theta_{atmstab}$$ Switch to configure which approach to atmospheric stability is used [integer] $$ \left\{ \begin{array}{ll} \textrm{Neutral conditions } & \Theta_{atmstab}=0 \\ \textrm{1 } & \Theta_{atmstab}=1 \\ \textrm{1 } & \Theta_{atmstab}=2 \end{array} \right.$$
rh_factor $$f_{RH}$$ Scaling factor to adjust the relative humidity data provided in the meteo_fl (\(RH_x\)) [real] 1
at_factor $$f_{AT}$$ Scaling factor to adjust the air temperature data provided in the meteo_fl (\(AT_x\)) [real] 1
ce $$C_E$$ Bulk aerodynamic transfer coefficient for latent heat flux [real] 0.0013
ch $$C_H$$ Bulk aerodynamic transfer coefficient for sensible heat flux [real] 0.0013

rain_sw $$\Theta_{rain}$$ Switch to configure rainfall input concentrations [boolean] .true. OR .false.
rain_factor $$f_R$$ Scaling factor to adjust the rainfall data provided in the meteo_fl (\(R_x\)) [real] 1
catchrain $$\Theta_{runin}$$ Switch that configures runoff from exposed banks of lake area [boolean] .true. OR .false. .false.
rain_threshold $$R_L$$ Daily rainfall amount (m) required before runoff from exposed banks occurs [real]
runoff_coef $$f_{ro}$$ Conversion fraction of infiltration excess rainfall to runoff in exposed lake banks [real]
Wind & wind-sheltering
cd $$C_D$$ Bulk aerodynamic transfer coefficient for momentum [real] 0.0013
wind_factor $$f_U$$ Scaling factor to adjust the windspeed data provided in the meteo_fl (\(U_x\)) [real] 1
fetch_mode $$\Theta_{fetch}$$ Switch to configure which wind-sheltering/fetch option to use. Modes 2 and 3 read a wind-direction column from the meteo_fl and require the &fetch block [integer] $$ \left\{ \begin{array}{ll} \textrm{No sheltering } & \Theta_{fetch}=0 \\ \textrm{Area-based scaling } & \Theta_{fetch}=1 \\ \textrm{Markfort length-scale } & \Theta_{fetch}=2 \\ \textrm{User input scaling table } & \Theta_{fetch}=3 \end{array} \right.$$ 0
Aws $$A_{WS}$$ Area scale controlling the effective-area sheltering relationship, \(A_{eff} = A\tanh(A/A_{WS})\) [real] Required for fetch_mode (\(\Theta_{fetch}\)) \(= 1\) 0
Xws $$x_{WS}$$ Accepted by the reader; planned for future update and not yet applied by any fetch_mode. Modes 2 and 3 take their sheltering from the &fetch block [real] - 0

Example 
&meteorology
				  !-- Met forcing options
				   met_sw      = .true.
				   lw_type     = 'LW_IN'

How this page is kept honest

Last checked against the source on 1 September 2026, at GLM 4.0.0 (commit df7a4be).

Everything documented here is cross-checked against the NAMELIST[] tables in src/glm_init.c, src/glm_bird.c and src/glm_plot.c. Those tables are the whole vocabulary: get_namelist() walks the code's list and looks each name up in your file, so a key the tables do not list is never consulted and is silently ignored — no warning, no error, just a default quietly left in place. That makes a wrong entry on this page more costly than a missing one, which is why the checks run in both directions.

Three scripts do the checking. audit_glm_config.py diffs block and variable names against the tables: 26 of 26 blocks documented, 239 of 312 variables, and 0 entries on this page that the code does not read. audit_glm_defaults.py compares the Default column with the initialisers in glm_globals.c and glm_init.c: 43 defaults compared, 0 disagreeing; the rest are symbolic, conditional or blank in one of the two places and are reported for review rather than guessed at. audit_glm_examples.py runs every key in the shipped glm-examples nml files past the same tables, and finds 2 that the code never asks for.

The 73 variables that the code reads but this page does not yet describe are concentrated in &snowice, &sediment and &outflow; they are being worked through, and none of them are stale — the gap is coverage, not correctness.
